这个示例自身即可用两种模式运行。

  1. 01

    默认：单进程

    MZGUI_TASK_MODE=inprocess go run ./examples/framework-agentd-showcase

    使用本地 TaskBackend，任务与窗口同生命周期。

  2. 02

    按需：多进程

    bash scripts/run-agentd-showcase.sh

    启动独立 agentd，桌面改用 gRPC TaskBackend。

  3. 03

    保留不变部分

    TaskBackend · DesktopService · frontend

    业务接口、Wails 服务和前端不随进程模式重写。
