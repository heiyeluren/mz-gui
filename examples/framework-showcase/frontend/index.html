把示例换成你的产品

保留 Framework，只修改应用身份、页面与业务服务。

  1. 01

    运行独立 APP

    go run ./examples/framework-showcase

    确认桌面窗口、状态读取与事件交互正常。

  2. 02

    修改应用身份

    examples/framework-showcase/mzgui.app.toml

    设置产品名、bundle ID、进程名、存储命名空间和能力集合。

  3. 03

    接入自己的业务

    framework/go/... · framework/ui-kit

    通过公共接口组合服务，在 Showcase 中替换页面和用例。
