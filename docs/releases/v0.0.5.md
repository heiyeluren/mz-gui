# MZ-GUI v0.0.5 发布说明

状态：已创建并推送 `v0.0.5` 与 `mz-gui-v0.0.5`；正式 GitHub Release 尚未创建。

## 主要变化

- 新增 Windows amd64 真机验证：全量 Go/UI、Named Pipe、单/多进程窗口与后台恢复。
- macOS 和 Windows 安装包均生成 ZIP、SHA-256 与 SBOM。
- 六个具有多消费者和跨平台证据的核心 API 升为 stable，其余保持 candidate/experimental。
- 增加 MediaSurface、MermaidDiagram、视觉基线与组件文档。
- 新增 SQLite DurableBus，与内存 MessageBus 共用契约，支持重启恢复与幂等。
- 增加并通过 30 分钟 Go/UI 并行 soak、性能验证入口和真实 Windows 截图；13500 批终端输出完整消费，Go 连接与 goroutine 增量均为 0。

## 已验证平台

- macOS Apple Silicon：Go/UI/消费者、单/多进程 GUI、任务恢复、安装包。
- Windows amd64：Go/UI/消费者、Named Pipe、单/多进程 GUI、任务恢复、安装包。

## 尚未完成

- macOS Intel 与 Linux 真机验证环境，当前不可用，保持未验证。
- 正式 GitHub Release 和 tag 干净消费者复验。

## 升级说明

从 v0.0.1 或 v0.0.4 升级时执行：

```bash
go get github.com/heiyeluren/mz-gui@v0.0.5
make check
```

React 使用实际 `mz-gui-ui-kit-0.0.5.tgz` 安装并运行类型检查与生产构建。不要直接改旧基线或批量升级 candidate API。
